# Chrome Dino RL — Tabular Reinforcement Learning Environment

Full implementation of the popular **Chrome Dino** game as an environment compatible with the standard **Gymnasium** API, designed for experimentation and research with **Tabular Reinforcement Learning algorithms** (Q-Learning, SARSA, and Expected SARSA).

## Project Structure

```text
.
├── dino_game/
│   ├── __init__.py
│   ├── dino_env.py             # Gymnasium DinoEnv environment definition
│   └── renderers/
│       ├── __init__.py
│       ├── pygame_renderer.py  # PyGame graphical renderer (human)
│       └── ansi_renderer.py    # ASCII text renderer (terminal)
│
├── deustorl/
│   ├── common.py               # Q-tables, policies (EpsilonGreedy, Max), evaluation
│   ├── helpers.py              # TensorboardLogger and discretization wrappers
│   ├── qlearning_fixed.py      # Q-Learning with Bellman correction on terminal states
│   ├── sarsa_fixed.py          # SARSA with Bellman correction on terminal states
│   └── expected_sarsa_fixed.py # Expected SARSA with Bellman correction on terminal states
│
├── examples/
│   ├── play_human.py           # Manual keyboard control
│   ├── random_agent.py         # Demonstration with random actions
│   ├── train_qlearning.py      # Q-Learning training and evaluation
│   └── full_experiment.py      # Bayesian optimization with Optuna and environment comparison
│
└── optuna/                     # SQLite databases and HTML reports generated by Optuna
```

## Scripts and Examples Guide (`examples/`)

### 1. Manual Play Mode: `play_human.py`
Allows testing the physics and game dynamics in real time using the keyboard:

```bash
python examples/play_human.py
```
* **Controls:**
  * **Space** or **Up Arrow:** Jump.
  * **Down Arrow:** Duck.
  * **No key:** Run upright (normal).

---

### 2. Random Agent: `random_agent.py`
Runs an agent taking uniform random actions (`action_space.sample()`) to verify rendering:

```bash
# Graphical mode with PyGame
python examples/random_agent.py --human

# ANSI text mode in terminal
python examples/random_agent.py
```

---

### 3. Individual Q-Learning Training: `train_qlearning.py`
Trains a Q-Learning agent for 2 million steps with default incremental speed and evaluates the learned policy displaying the game in PyGame (using the `--human` flag) or in the ANSI console:

```bash
# Train and visualize in graphical window
python examples/train_qlearning.py --human

# Train and evaluate in ANSI console
python examples/train_qlearning.py
```

---

### 4. Full Experiment and Optuna Optimization: `full_experiment.py`
Comprehensive experimentation script based on Optuna (with TPE sampler). Allows comparing **SARSA**, **Expected SARSA**, and **Q-Learning**, benchmarking two environments of varying difficulty:

1. **`dino_constant_speed` study:** Stationary easy environment ($1,620$ states).
2. **`dino_variable_speed` study:** Dynamic hard environment with acceleration ($4,860$ states).

#### Execution commands:

* **Run both studies and generate the final comparison:**
  ```bash
  python examples/full_experiment.py --mode both
  ```

* **Run only the constant speed study:**
  ```bash
  python examples/full_experiment.py --mode constant
  ```

* **Run only the variable speed study:**
  ```bash
  python examples/full_experiment.py --mode variable
  ```

* **Customize the number of trials and training steps:**
  ```bash
  python examples/full_experiment.py --mode both --n-trials 20 --n-steps 500000
  ```

#### Files and visualizations generated by Optuna:
Results are stored in a shared SQLite database (`optuna/optuna.db`). For each completed study (`optuna/<study_name>/`), the following files are exported:
* `best_trial.json`: Best hyperparameters and achieved rewards.
* `optimization_history.html`: Reward evolution across trials.
* `contour.html`: 2D parameter relationships.
* `slice.html`: Objective function slice plot per parameter.
* `param_importances.html`: Hyperparameter importance and influence plot.

If both studies are executed (`--mode both`), the following is also generated in the root directory:
* `optuna/comparison_summary.json`: Direct comparative summary between both environments.
